Tailwind v4 bringt einen grundlegenden Wechsel: **CSS-first-Konfiguration** statt JavaScript.

## Was hat sich geändert?

- Keine `tailwind.config.js` mehr nötig
- Konfiguration direkt im CSS über `@theme`
- Native OKLCH-Farben
- Eingebaute Container Queries
- Deutlich schnellere Builds

## Integration in Astro v7

Wir binden das Vite-Plugin direkt ein:

```javascript title="astro.config.mjs"
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  vite: {
    plugins: [tailwindcss()],
  },
});
```
